## Executando localmente

Cada projeto possui arquivos e scripts próprios. Para iniciar um projeto, entre na respectiva pasta, instale as dependências e utilize o script de desenvolvimento.

```bash
cd meu-app-angular       # ou projeto-react-01, projeto-next, projeto-vue
npm install
```

Consulte o README dentro de cada projeto para os comandos específicos.
